# AI Policy

AI coding tools are used in this project as productivity aids, the same
way we use any other development tool. Every decision, review, and
authorship credit belongs to a human, except automated dependency updates.

## For contributors

- You may use AI tools to draft, refactor, or explore ideas.
- You are the author of everything you submit. You must be able to
  explain and defend every change.
- Keep PRs small and atomic. Each PR must leave the repository in a
  working state and be scoped to a single logical change.
- Do not list an AI system as a co-author. Copyright for all
  contributions rests with the human contributor.
- Do not post AI-generated text to issues, discussions, or review
  comments without reading and editing it first.

## For reviewers

- All non-trivial changes require approval from a named human reviewer
  before merge, regardless of how the code was drafted.
- Reviewers read every line they approve. If a PR is too large to
  review carefully, ask for it to be split.

## Scope

This repository publishes data and analysis scripts for a behavioral
evaluation of in-browser WebMCP tool surfaces. AI tools were used during
the underlying experiment and in preparing this repository. The recorded
run data is verbatim model output; it is published as observed, not
edited. Human authors are responsible for the methodology, the rubric
definitions, and every claim drawn from the data.

We reserve the right to close PRs that do not meet these standards
without review. Repeated violations or patterns of low-effort
AI-generated submissions may result in restrictions on future
contributions.
